# Project Overview

This repository contains SQL exercises completed as part of an ongoing course "SQL and PostgreSQL: The complete developer´s guide" by Stephen Grider.

The exercises are based on tasks provided by the course, while the SQL queries and solutions are independently developed.

The focus is not only on completing the exercises, but also on developing a structured approach to solving problems using SQL. Each exercise includes comments documenting my thought process, technical decisions, and the reasoning behind the chosen solutions.

## Objectives

- Develop practical skills in PostgreSQL and SQL
- Translate problem requirements into working SQL queries
- Investigate database structures and understand the data before developing solutions
- Identify potential data issues and consider relevant edge cases
- Select appropriate SQL functions, operators, and query techniques
- Understand alternative solutions and explain technical decisions
- Write clear, readable, and maintainable SQL
- Improve the ability to document and communicate technical reasoning

## Context

The exercise descriptions and requirements originate from the PostgreSQL course. The SQL implementations, problem-solving approaches, and accompanying explanations are my own work.

## Technologies used

- PostgreSQL – Relational database management system used to write and execute SQL queries
- pgAdmin 4 – Database administration and query management
- Visual Studio Code – Code editor used to organise, and document SQL scripts
- Git – Version control system used to track changes and manage project revisions
- GitHub – Repository hosting used to store and share the project
- Udemy – Learning platform providing the PostgreSQL course
